# Teclado Virtual 🎹💻  



https://github.com/user-attachments/assets/bc76c840-757d-4a2d-a694-5f3f437f8c74


Este es un proyecto de **teclado virtual** desarrollado utilizando solo **HTML** y **CSS**. El objetivo de este proyecto es recrear la experiencia de un teclado digital visualmente funcional, ideal para reforzar habilidades de diseño y estilización web.

## 🌟 Visión General  
Este teclado virtual simula la distribución de un teclado QWERTY estándar, con teclas estilizadas y efectos visuales al interactuar con ellas.

## 🖥️ Tecnologías Utilizadas  
- **HTML5**: Para estructurar el teclado y las teclas.  
- **CSS3**: Para estilizar el teclado, agregar efectos al presionar las teclas y asegurar su visualización responsiva.

## 🚀 Características Destacadas  
- **Diseño responsivo**: El teclado se adapta a distintos tamaños de pantalla.  
- **Efectos visuales**: Las teclas cambian de estilo cuando son presionadas.  
- **Uso de Flexbox**: Implementación eficiente de estas propiedades CSS para una correcta disposición de las teclas.
